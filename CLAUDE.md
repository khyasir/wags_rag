# wags_rag

## Plan & Review

### Before starting work
- Always start in plan mode to make a plan.
- Write the plan to `.claude/tasks/TASK_NAME.md`.
- The plan must be a detailed implementation plan with the reasoning behind it, plus tasks broken down.
- If the task requires external knowledge or a specific package, research first (use the Task tool).
- Don't over-plan. Always think MVP.
- Once the plan is written, ask me to review it. Do not continue until I approve the plan.
- Trivial fixes under 10 lines: skip plan mode.

### While implementing
- Update the plan as you work.
- After completing each task, append a detailed description of the changes made, so the work can be handed over to another engineer easily.
